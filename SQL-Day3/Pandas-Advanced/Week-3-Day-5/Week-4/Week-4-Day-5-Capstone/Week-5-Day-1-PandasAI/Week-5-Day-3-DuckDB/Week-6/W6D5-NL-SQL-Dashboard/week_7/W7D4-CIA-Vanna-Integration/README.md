# W7D4 – CIA SQL Mode: Vanna Integration

## 1. Project Overview

This task implements Vanna AI integration for the CIA SQL Analyst backend to answer natural-language questions using the CRM SQLite database.

The integration uses a locally hosted Ollama LLM, a custom SQL execution tool, Agent Memory, and FastAPI.

## 5. Vanna Agent Memory – Five Example Q&A Pairs

Five CRM Question-SQL examples were saved successfully using `DemoAgentMemory`.

### Example 1: Total Customer Count

**Question:**
How many customers are there in the CRM database?

**SQL:**

```sql
SELECT COUNT(*) AS total_customers FROM customers;
```

### Example 2: Total Deal Value

**Question:**
What is the total deal value of all customers?

**SQL:**

```sql
SELECT SUM(deal_value) AS total_deal_value FROM customers;
```

### Example 3: Won Deals

**Question:**
How many deals are in the Won stage?

**SQL:**

```sql
SELECT COUNT(*) AS won_deals
FROM customers
WHERE deal_stage = 'Won';
```

### Example 4: Customers by Lead Source

**Question:**
How many customers came from each lead source?

**SQL:**

```sql
SELECT lead_source, COUNT(*) AS customer_count
FROM customers
GROUP BY lead_source
ORDER BY lead_source;
```

### Example 5: Average Deal Value

**Question:**
What is the average deal value of all customers?

**SQL:**

```sql
SELECT AVG(deal_value) AS average_deal_value
FROM customers;
```
