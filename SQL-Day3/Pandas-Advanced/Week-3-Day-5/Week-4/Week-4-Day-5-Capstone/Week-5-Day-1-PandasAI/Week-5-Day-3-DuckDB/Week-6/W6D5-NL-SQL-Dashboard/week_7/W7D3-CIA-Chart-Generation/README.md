# W7D3 - CIA Chart Generation

## Plotly + ECharts

### Project Overview

This project demonstrates interactive data visualization
using Plotly and ECharts.

### Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- ECharts
- Jupyter Notebook
- HTML

### Dataset Details

A sample monthly sales dataset was created with 6 records
and 4 columns:

- Month
- Revenue
- Orders
- Customers

### Plotly Visualizations

1. Monthly Revenue Bar Chart
2. Monthly Revenue Trend Line Chart
3. Orders vs Customers Scatter Plot
4. Monthly Revenue Distribution Donut Chart

### ECharts Visualizations

1. Monthly Revenue Bar Chart
2. Monthly Revenue Line Chart
3. Monthly Revenue Donut Chart

### Project Structure
